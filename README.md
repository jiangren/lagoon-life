# 海湾生活 · Lagoon Life

[打开网页试玩](https://jiangren.github.io/lagoon-life/) · [橙宝的学习乐园](https://jiangren.github.io/learning-garden/)

这里发布《海湾生活》的 Godot 网页构建。当前版本为 0.45.1。手机和平板可使用虚拟摇杆，桌面可使用键盘和鼠标。游戏进度保存在当前浏览器，可在开始界面导入和导出存档，也可用学习乐园的家长账号备份到云端。

GitHub Pages 从 `main` 分支根目录发布。更新时保留带版本和哈希的资源文件，同时更新 `index.html`、`version.json` 和 `service-worker.js`。
